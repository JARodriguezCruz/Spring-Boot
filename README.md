🚀 Spring Boot API

API REST desarrollada con Spring Boot para la gestión de usuarios y datos.

## 🚀 Características
- API RESTful
- CRUD completo
- Integración con base de datos
- Arquitectura en capas

## 🛠️ Tecnologías
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL / H2

## 📂 Estructura
- `controller/`
- `service/`
- `repository/`
- `entity/`
